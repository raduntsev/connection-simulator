# Виртуальный стенд «Основы автоматики»

Веб-симулятор лабораторного стенда «Основы автоматики» (ОА2-СН) для СПО. Работает в браузере на компьютере, планшете и телефоне, установка не нужна.

Студент соединяет гнёзда проводами на фотографии стенда, переключает тумблеры и кнопки, ручками меняет R и C и наблюдает за реле, логическими элементами, счётчиками и осциллографом.

## Готовые схемы

- ЛР 1: дребезг тумблера SA2; тумблер SA1 со встроенной защитой; дребезг контактов реле K1
- ЛР 2: антидребезг на RC-фильтре; антидребезг на триггере
- ЛР 3: время включения реле
- ЛР 4: задержка на цифровых элементах

## Запуск

Откройте `index.html` в браузере. Для публикации подойдёт любой статический хостинг (например, GitHub Pages).

## Состав

- `index.html`, `style.css`, `app.js` — приложение
- `stand.jpg` — фото стенда
- `imsmanifest.xml` — манифест SCORM 1.2 для загрузки в электронный курс (без передачи результатов)

## Допущения модели

Логика 5 В, входы с подтяжкой; число импульсов дребезга выбирается случайно в заданных пределах; параметры реле и дребезга настраиваются в приложении по данным реального стенда; программируемое реле ONI не воспроизводится.
